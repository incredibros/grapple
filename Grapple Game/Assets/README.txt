Shortcuts

EDITOR:
F: Focus camera on the selected object.
W: Move tool (translate).
E: Rotate tool.
R: Scale tool.T: Rect tool (best for 2D and UI).
Y: Transform tool (combines move, rotate, and scale).

0: Deselect All
1: Select Ground Brush
2: Select Semi Solid Brush
3: Select Hazard Brush
4: Select Sprite Brush
5: Select Half Ground Brush
6: Select Half Semi Solid Brush
7: Select Half Hazard Brush
8: Select Half Sprite Brush

P: Move Player

U: Spawn Checkpoint
O: Spawn Orb
I: Spawn Peg

GAME:
Move: W A S D / Arrow Keys
Aim: Mouse Movement / Player Input
Jump: Space
Grapple: Left Click / O
Pull: Right Click / P
Next Scene: N
Toggle Cursor Mode: H and O and G
Pause Menu: Esc
