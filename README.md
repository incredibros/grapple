# Mount Vulcano

A fast-paced 2d platformer game focused on grappling, momentum, and movement control.

## Play the Game

The game website is linked directly in this repository. Open the provided Pages link to play in your browser.

## Controls

| Action          | Input                  |
| --------------- | ---------------------- |
| Move            | `W A S D / Arrow Keys` |
| Aim             | `Mouse Position`       |
| Jump            | `Space`                |
| Grapple         | `Left Click`           |
| Pull To Grapple | `Right Click`          |
| Pause Menu      | `Esc`                  |

## Controller Support

The game also supports controllers.

## Gameplay

Use your grapple to swing across obstacles, gain momentum, and navigate the environment.

* Move the mouse to aim your grapple
* Use **Left Click** to fire your grapple
* Use **Right Click** to pull yourself toward the grapple point
* Your grapple and pull reset when you touch the ground
* Only one grapple can be active at a time

## Tips

* Use momentum to travel farther
* Time your jumps and grapples carefully
* Landing resets your grapple and pull abilities
